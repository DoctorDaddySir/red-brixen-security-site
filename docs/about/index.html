01 / BACKGROUND

Understanding a system
means questioning it.

I work at the intersection of offensive security and software engineering. My focus is understanding how applications break—and how to build them better.

My engineering background spans backend services, APIs, enterprise integrations, and database-driven applications. Working on these systems has shaped the way I think about security: follow the data, understand the trust boundaries, and get close to the code.

That perspective carries into secure code review, authorization improvements, dependency management, and vulnerability remediation. Penetration testing adds another lens—a way to question what a system assumes and explore where those assumptions can fail.

I also value making technical ideas useful to other people. Instruction and mentorship are part of my background, alongside the practical work of building and securing software.
